# Preserve

Keep a garden at its favorite stage. Seal delicate blocks. Hold a structure in place. Pause a machine, then let it run again.

An experimental Minecraft **26.2** mod for **Fabric and NeoForge**, by **DeisDev**. Requires Java 25. In development; survival features and compatibility are being implemented.

Build both loader jars with `./gradlew build`. Use the jar for your loader from its `build/libs` folder.
